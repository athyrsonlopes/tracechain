# tracechain
# Sistema de Rastreabilidade Alimentar (TCC)

Sistema web para rastreabilidade de alimentos usando blockchain e QR Code.

## Stack planejada
- Ruby on Rails (backend + API)
- NextJS
- PostgreSQL
- Blockchain para registro imutável
- QR Code para consulta de histórico
